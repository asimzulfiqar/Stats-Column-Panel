# Changelog

## 1.0.0

- Initial release of **Stats Column Panel** (`asimzulfiqar-statscolumn-panel`).
- Responsive stapled vertical columns of Stat cards and section headings that stay grouped together on mobile and desktop.
- Support for 4 number formatting styles: German grouped (`10.000,56`), English grouped (`10,000.56`), Plain dot (`10000.56`), and Plain comma (`10000,56`).
- Support for Stat calculations (`lastNotNull`, `last`, `firstNotNull`, `first`, `min`, `max`, `mean`, `sum`, `count`, `rowSelector`), thresholds, color modes, value mappings, info tooltips `(i)`, and variable/field/viewport visibility rules.
